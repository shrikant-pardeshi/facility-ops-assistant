# Mains Power Failure Response

## Immediate actions
1. Confirm DG sets have started on AMF (auto mains failure) and taken load within 15 seconds.
2. Confirm UPS is supplying critical loads; check UPS battery backup time remaining.
3. Check that lifts have homed to the ground floor or are running on DG supply; check for entrapment (see SOP-LIFT-001).
4. Inform the helpdesk to notify occupants if the outage is expected to be long.

## If DG does not start
Try a manual start once. If it still fails, shed non-essential loads, inform the Facility Manager, and call the DG AMC vendor. A total power failure with DG failure is a P1 incident.

## On mains restoration
Confirm stable mains supply for 5 minutes before changeover back to mains. Check that UPS returns to normal mode and batteries are charging.

## Records
Record outage start/end, DG run hours and fuel consumed.
